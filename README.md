This repository hosts the Windows installer for Reflect Forge. What the app does, pricing and terms are on the website: <https://forge.lsrabbit.space>

这个仓库只放反思锻造台的 Windows 安装包。软件做什么、价格和条款都在网站上：<https://forge.lsrabbit.space>

## Download · 下载

Get the installer from the [latest release](https://github.com/LSRabbit6/reflect-forge-releases/releases/latest).

安装包在[最新发布页](https://github.com/LSRabbit6/reflect-forge-releases/releases/latest)。

## Before you install · 安装前

- **Activation code.** The app asks for an activation code on first launch. Codes are sold on the website. Without one the app does not run.
- **Windows 11 (64-bit).** Windows 10 has not been tested yet. There is no Mac version yet.
- **Claude Code or Codex** installed and signed in on the same computer, with your own session records in it.
- **The installer is not code-signed yet.** Windows SmartScreen may warn about an unknown publisher; choose *More info → Run anyway*. Each release lists the installer's SHA-256 so you can check the file you downloaded.

<!-- -->

- **激活码。** 第一次打开时软件会要激活码。激活码在网站上购买，没有激活码软件不能用。
- **Windows 11（64 位）。** Windows 10 还没实测。Mac 版还没有。
- 同一台电脑上装好并登录了 **Claude Code 或 Codex**，里面有你自己的会话记录。
- **安装包暂未做代码签名。** Windows 可能提示「未知发布者」，点「更多信息 → 仍要运行」即可。每个发布页都写了安装包的 SHA-256，可以用来核对下载到的文件。
